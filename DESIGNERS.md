## Shortlist

### 1. DIA Studio — *type-driven, kinetic, broadcast-grade motion*
- **URL:** https://dia.tv
- **Location:** New York / Barcelona
- **Strengths:** kinetic typography, brand systems in motion, identity loops
- **Rate band:** top studio · $40k+ for full brand motion packages
- **Fit for xrpldashboard:** Spotify / Nike / MoMA past client list bring institutional polish to "edgy". Visual language (mono type, gradients, grid systems) maps cleanly onto a data dashboard brand. Not crypto-native.

### 2. Hellohikimori — *cyber, futuristic, hyper-detailed 3D + motion*
- **URL:** https://hellohikimori.com
- **Location:** Paris
- **Strengths:** 3D, glitch/cyber, particle FX, sci-fi UI mockups
- **Rate band:** mid-to-top · $25–60k
- **Fit:** Their entire aesthetic *is* "edgy high-tech." Past work for Nike, Audi, gaming brands. Strong hero loops with depth.

### 3. Tendril — *premium 3D motion, abstract data-feeling visuals*
- **URL:** https://tendril.ca
- **Location:** Toronto / Amsterdam
- **Strengths:** 3D, abstract simulation, particles, generative
- **Rate band:** top studio · $40k+
- **Fit:** Abstract simulation reels read like "what blockchain *feels* like." Has done fintech. Probably overkill on budget, but worth the reference.

### 4. Anagram — *bold editorial motion, type + grid, restrained futurism*
- **URL:** https://anagram.studio
- **Location:** Geneva
- **Strengths:** brand identity in motion, editorial systems, restrained "smart" futurism
- **Rate band:** mid-studio · $15–30k
- **Fit:** Specifically matches the mono-font, gradient, data-dense vibe. xrpldashboard's existing UI is already adjacent.

### 5. Baugasm / Vasjen Katro — *solo, prolific, glitch + gradient + typography*
- **URL:** https://baugasm.com
- **Location:** Albania (LATAM/EE/Asia flag — strong non-US/EU talent)
- **Strengths:** gradients, glitch, poster-style hero stills and loops
- **Rate band:** indie freelance · $3–8k per piece
- **Fit:** His palette (cyan/pink/purple on dark) is **exactly** xrpldashboard's. Fast turnaround.

### 6. Zach Lieberman — *generative / creative-code motion artist*
- **URL:** https://zachlieberman.com (also IG @zach.lieberman)

- **Strengths:** generative particles, openFrameworks, code-driven motion

## If I had to pick 3 today

1. **Baugasm (Vasjen Katro)** — palette is a near-perfect match, indie rates, fast. Lowest-risk fit for a hero loop.
2. **Anagram** — if the ask is the whole brand-in-motion system (logo intro, page transitions, hero), not just one asset. Mono-grid sensibility aligns.
3. **Lusion** — if the ambition is an *interactive* WebGL hero driven by live XRPL data. Highest ceiling, highest cost.

Skip Tendril / DIA unless budget is clearly $40k+; they're references, not realistic hires for a solo-operated dashboard project.
