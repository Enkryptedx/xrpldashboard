{{ _('About xrpldashboard') }}

{{ _('A public-good ledger dashboard for the XRP Ledger. Free for retail users, forever. A public-utility approach to ledger data: opinionated about clarity, no token, no DEX, no upsells.') }}

{{ _('Launched: May 9, 2026.') }} {{ _('We\'re live and actively smoothing out rough edges. If you spot something that looks wrong or doesn\'t render right,') }} {{ _('tell us') }} — {{ _('we\'d rather hear it from you than ship around it.') }}

{{ _('Mission') }}

{{ _('Help XRP holders understand on-chain activity. Not get rich. Not sell liquidity. Not push tokens. Just data, explained well, for people who want to understand what they own.') }}

{{ _('Principles') }}

  1. {{ _('Retail-free, forever.') }} {{ _('No paywall will ever bump a retail user.') }}
  2. {{ _('Plain language over jargon.') }} {{ _('Every metric is explained simply.') }}
  3. {{ _('Link out generously.') }} {{ _('We\'re a dashboard, not a directory — we send you to XRPSCAN, Bithomp, and others for the granular details they do better.') }}
  4. {{ _('Editorial voice is part of the product.') }} {{ _('We make choices about what to show and how — that\'s the work.') }}
  5. {{ _('Trust over features.') }} {{ _('We never sensationalize. We never imply intent we can\'t verify. We\'d rather omit than overstate.') }}
  6. {{ _('Mission-first.') }} {{ _('The funding model serves the mission, not the other way around.') }}
  7. {{ _('Open source.') }} {{ _('MIT-licensed. The full source is on GitHub — anyone can fork, audit, or self-host.') }}
  8. {{ _('Transparent metrics.') }} {{ _('Our visitor analytics and our infrastructure status') }} (/health) {{ _('are both publicly viewable. Nothing to hide.') }}

{{ _('How it works') }}

{{ _('Every live number on this site is computed directly from the XRP Ledger. We do not aggregate or re-publish data from third-party APIs (Bithomp, XRPSCAN, xrpl.to, XPMarket, DefiLlama). Their products are good — but if we depended on them for our data, we\'d just be a wrapper for their work.') }}

{{ _('Live ledger data') }}

{{ _('Comes from public XRPL nodes (currently Ripple\'s') }} s1.ripple.com {{ _('and') }} s2.ripple.com). {{ _('A node is just a peer in the consensus network — it can\'t lie about ledger contents without the rest of the network rejecting it. The data is canonical.') }} {{ _('Disclosure:') }} {{ _('Ripple\'s documentation states their public servers are not intended for sustained business use. The plan is to migrate to the community-operated cluster') }} wss://xrplcluster.com {{ _('before sustained traffic warrants it, and to run our own rippled node as the project grows. The full per-surface cache and source breakdown is on') }} /methodology.

{{ _('Reference labels') }}

{{ _('Token display names and named-account labels are hand-curated in our open-source repo. Each label has a verifiable source URL. Contributions go through public PR review (see') }} TOKEN_NAMES.md {{ _('and') }} KNOWN_ACCOUNTS.md). {{ _('Same pattern mempool.space uses for its mining-pool list.') }}

{{ _('Cross-checking') }}

{{ _('We link out to XRPSCAN, Bithomp, and other sources so you can verify our numbers against alternative readings whenever you want. Linking out for verification strengthens the trust principle, not weakens it.') }}

{{ _('Methodology notes') }}

  • {{ _('Whale movement') }} — {{ _('any single XRP transaction of') }} {{ _('50,000 XRP or more') }}. {{ _('Smaller transfers don\'t appear on') }} /whales.
  • {{ _('Token labels') }} — {{ _('only displayed when we can cite a first-party source for the issuer (exchange page, project') }} .toml, {{ _('etc.). Unverified issuers render unlabeled rather than guessed.') }}

{{ _('Every external dependency we have — XRPL nodes, the Postgres provider, the CDN — is named on') }} /methodology, {{ _('with the cache TTL of every surface that touches it. If a number on this site is wrong, that\'s where you find out why.') }}
