{{ _('What is an XRPL NFT? (XLS-20 in one page)') }}

{{ _('XLS-20 is the amendment that added native non-fungible tokens to the XRP Ledger in October 2022. Unlike NFTs on smart-contract chains, XRPL NFTs are ledger-native objects — not user-deployed contracts — so every mint, transfer, and burn is a first-class transaction type validated by consensus.') }}

{{ _('Five transaction types:') }}

NFTokenMint — {{ _('creates a new NFToken tied to an issuer + taxon (collection ID).') }}
NFTokenBurn — {{ _('destroys an NFToken. Only the owner or the issuer (if burnable-flag set) can burn.') }}
NFTokenCreateOffer — {{ _('publishes a buy or sell offer at a given price, in XRP or an IOU.') }}
NFTokenCancelOffer — {{ _('withdraws a previously-published offer.') }}
NFTokenAcceptOffer — {{ _('matches a pair of offers and settles ownership. This is the "sale" event.') }}

{{ _('The') }} NFTokenID {{ _('is a 256-bit identifier that encodes the issuer, the taxon (collection ID within an issuer), a sequence number, and flags — so given only the ID, anyone can decode which issuer it came from, without asking a marketplace.') }}
