{{ _('What is the XRP Ledger?') }}

{% trans -%} Picture a notebook. Every few seconds, someone adds a new page. Each page lists everything that happened in the last few seconds — who sent money to whom, who opened a trade, who issued a new token. Once a page is written down, it can never be changed. {%- endtrans %}

{% trans -%} The XRP Ledger is that notebook. The pages are called "ledgers." A new one closes roughly every three to five seconds. Anyone in the world can read every page that has ever been written, all the way back to the very first one in 2012. {%- endtrans %}

{{ _('Who actually writes to it?') }}

{% trans -%} There is no central company in charge of the notebook. Instead, about 150 independent computers around the world — called validators — propose what the next page should say. They are run by universities, exchanges, banks, the XRP Ledger Foundation, and ordinary technically-inclined people in different countries. {%- endtrans %}

{% trans -%} Every few seconds, each validator independently looks at the pending transactions, decides which ones it considers valid, and broadcasts its proposal. The validators then compare proposals and agree on a single shared answer for that page. If more than 80% of the trusted validators agree, that page is written. If they don't agree, no page is written until they do. This is called consensus. {%- endtrans %}

{% trans -%} Because the writing is spread across many independent operators in different jurisdictions, no single one of them can rewrite history, censor a transaction permanently, or shut the network down. The XRPL has run with very high uptime since 2012. {%- endtrans %}

{{ _('What is XRP?') }}

{% trans -%} XRP is the native asset of the ledger — think of it as the postage stamp on every transaction. To write anything to the notebook, you pay a tiny amount of XRP. The fee is destroyed (not paid to anyone), which keeps the cost of spamming the network meaningfully high while the cost of a real transaction stays near-zero. {%- endtrans %}

{% trans -%} Beyond paying for transactions, XRP is also used as a unit of value and as one of the assets traded inside the ledger's own on-chain exchange. It was sometimes described as a bridge currency between other assets, though in practice most trades on XRPL today route directly through automated-market-maker pools rather than through XRP as an intermediate hop. {%- endtrans %}

{{ _('How fast and how expensive is it?') }}

{% trans -%} A transaction is final in three to five seconds — the time it takes the next page to close. The base fee for a standard payment is on the order of 0.00001 XRP, which at typical prices is a small fraction of a US cent. Fees rise automatically if the network gets congested, then fall back when it clears. {%- endtrans %}

{% trans -%} Speed and cost are not promises from a marketing page — they are properties of how the protocol is built. You can watch a transaction confirm on any ledger explorer, including this one, and time it yourself. {%- endtrans %}

{{ _('What can the ledger do besides send XRP?') }}

{% trans -%} The XRP Ledger is unusual among blockchains in that many features common on other chains are built directly into the protocol — not added later as smart-contract code. That means they share the network's speed, low cost, and predictable behavior. {%- endtrans %}

  • {{ _('Issued tokens.') }} {% trans -%} Anyone can issue a token on XRPL — a stablecoin, a reward point, a tokenized share. Tokens live as balances on the ledger and can be sent, traded, and held just like XRP. {%- endtrans %}
  • {{ _('On-chain exchange.') }} {% trans -%} There is a built-in order book and automated-market-maker system. You can trade XRP for any issued token, or one token for another, directly from your wallet — no separate exchange contract required. {%- endtrans %}
  • {{ _('Multi-purpose tokens (MPTs).') }} {% trans -%} A newer token type designed for real-world assets — bonds, money-market funds, regulated instruments — with built-in fields for issuance metadata, supply tracking, and authorization controls. {%- endtrans %}
  • {{ _('Lending (in progress).') }} {% trans -%} Native on-chain lending is being added by amendment — a way for token holders to lend and borrow against ledger-resident assets without leaving the network. {%- endtrans %}

{% trans -%} Real institutions are already using the ledger this way. Archax tokenizes regulated financial instruments on XRPL; Ondo Finance launched a pilot tokenizing US Treasury exposure on the ledger in May 2026. These are not promises about a future — they are live products you can look up. {%- endtrans %}

{{ _("What it's not designed for") }}

{% trans -%} The XRP Ledger is deliberately not a platform for arbitrary computer programs. Networks like Ethereum let anyone deploy any program that other people can then trigger; the XRPL chose a different shape, where a fixed set of well-understood transaction types is built into the protocol and runs the same way every time. {%- endtrans %}

{% trans -%} The trade-off is straightforward: less flexibility, more predictability. If your use case fits one of the built-in transaction types — payments, token issuance, exchange, MPTs, lending — it runs fast and cheap. If your use case is "I want to deploy an arbitrary new program," XRPL is not the chain for that. {%- endtrans %}

{{ _('Who decides what changes?') }}

{% trans -%} Big changes to how the ledger works — new transaction types, new fields, new behavior — happen through amendments. Anyone can write one. To activate, an amendment has to be supported by at least 80% of the trusted validators for two consecutive weeks. If support drops, the amendment fails. {%- endtrans %}

{% trans -%} No company controls this vote. No single country controls it. The validators themselves — universities, exchanges, foundations, individuals — each choose what to support. The result is that the network changes only when a broad cross-section of operators agree it should. {%- endtrans %}

{{ _('Why this matters') }}

{% trans -%} Most of what people mean when they say "blockchain" — money that moves without a bank, assets that anyone can issue, a public record that no one can tamper with, an exchange built into the protocol itself — the XRP Ledger has been doing for over a decade. Quietly, cheaply, and at very high uptime. {%- endtrans %}

{% trans -%} The point isn't to make you a believer. The point is that everything described on this page is verifiable by anyone with a browser. The numbers on this site come straight from public XRPL nodes, and we tell you exactly which ones on the methodology page. {%- endtrans %}

{{ _('One-sentence summary') }}

{% trans -%} The XRP Ledger is a public, shared, near-real-time financial notebook that about 150 independent operators agree to write, in which XRP is the postage stamp and the rules — for payments, tokens, exchange, and assets — are baked into the protocol itself. {%- endtrans %}

{{ _('Verify it yourself') }}

{% trans -%} None of this requires trust. Every claim on this page can be checked directly against the XRP Ledger using public tools. {%- endtrans %}

  • {{ _('Watch ledgers close.') }} {% trans -%} Open the dashboard homepage. The pulsing chip in the top right shows the current ledger index and ticks every few seconds — that's the network writing a new page in real time. {%- endtrans %}
  • {{ _('Read any past page.') }} {% trans -%} Any ledger explorer — XRPSCAN, Bithomp, the XRPL Foundation's tools — lets you pull up any historical ledger by number and see exactly what transactions it contained. {%- endtrans %}
  • {{ _('Check our numbers.') }} {% trans -%} Every metric on xrpldashboard links to the data source it came from, and the full caching and methodology breakdown is on /methodology. If a number looks wrong, the audit trail is open. {%- endtrans %}
  • {{ _('Read the protocol.') }} {% trans -%} The XRP Ledger code and documentation are open-source. Anyone can read the consensus algorithm, the transaction types, and the amendment process, and run their own node if they want to. {%- endtrans %}
